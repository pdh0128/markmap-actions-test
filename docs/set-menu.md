# 세트 메뉴 영양 분석

- 열량: 582 kcal
- 당류: 8g
- 단백질: 27g
- 포화지방: 11g
- 나트륨: 902mg

### 후렌치 후라이 M (114g)

- 열량: 324 kcal
- 당류: 0g
- 단백질: 5g
- 포화지방: 1g
- 나트륨: 282mg

### 코카콜라 M (425ml)

- 열량: 133 kcal
- 당류: 33g
- 단백질: 0g
- 포화지방: 0g
- 나트륨: 9mg

### 세트 합계

- 열량: 1,039 kcal
- 당류: 41g
- 단백질: 32g
- 포화지방: 12g
- 나트륨: 1,193mg

## 후렌치 후라이의 위험 요소

### 지방

- 고온 튀김 → 포화지방 증가
- 식물성 기름 사용

### 나트륨

- 조리 후 첨가 소금: +282mg

### 발암 가능 물질

- 아크릴아마이드(Acrylamide) 생성
- 장기 섭취 시 보건학적 위해 우려

### 혈당

- 감자 전분의 높은 GI
- 혈당 스파이크 가속화

## 코카콜라의 당류 위험성

### 수치

- 열량 133kcal 전량이 당류에서 발생
- 당류 33g (첨가당 10% 이내 지침 위협)

### 대사 기전

- 액상 당분 → 고형 음식보다 빠른 흡수
- 췌장 인슐린 분비 세포 과부하
- 장기적 제2형 당뇨병 발병 위험

## 세트 조합의 영양 불균형 심화

- 열량: 하루 권장량의 52%를 한 끼에 충족
- 30대 여성 기준: 하루 필요 열량의 54.7%
- 나트륨: 하루 제한량의 60% 초과
- 당류: 41g으로 하루 첨가당 기준 위협
- 식이섬유: 극히 부족
