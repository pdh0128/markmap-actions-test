# 빅맥 지수와 경제적 분석

## 빅맥 지수란

- 이코노미스트 지가 1986년 도입
- 국가 간 물가 수준·통화 가치 비교 지표
- 전제: 동일 제품의 가격은 구매력 평가(PPP) 환율로 수렴

## 2024~2025년 한국 현황

### 가격

- 한국: 약 5,500원
- 미국: 약 5.79달러

### 환율 분석

- PPP 환율: 실제 환율보다 낮게 산출
- 원화 저평가: 달러 대비 약 25~35%
- 의미: 한국 소비자의 상대적 구매력이 낮음

## 영양 접근성과 사회적 함의

### 저렴한 고칼로리 식품 접근성

- 상대적으로 낮은 비용으로 빅맥 구매 가능
- 저소득층의 고칼로리·저영양 식단 노출 가속화
- 영양 불평등 심화 가능성

## 식량 안보와 영양 균형

### 빅맥이 보편화한 식단 패턴

- 전분 + 고기 위주
- 채소 비중: 전체 중량의 5% 미만
- 신선 채소·다양성 부족

### 장기적 보건 영향

- 식이섬유 부족
- 장내 미생물 환경 불균형(Dysbiosis)
- 대사성 질환 발병률 상승과의 상관관계

## 가공식품 표준화의 역설

- 편리함·일관성 → 소비자 선호도 증가
- 영양 다양성 감소 → 공중 보건 위협
- 글로벌 확산 → 전통 식문화 약화
