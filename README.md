# 글로벌 가공식품의 영양학적 표준화와 보건학적 영향

## 연구 대상

- 맥도날드 빅맥 (Big Mac)
- 출시: 1967년 미국 펜실베이니아주
- 의의
  - 전 세계 가공식품 산업의 표준
  - 현대 식문화의 상징적 지표
  - 빅맥 지수(Big Mac Index)의 기초

## 연구 목적

- 거대 영양소 및 미세 영양소 구성 분석
- 식품의약품안전처 기준치와 비교
- 임상적·보건학적 함의 도출
